# 💎 Diamonds Data Explorer – Streamlit App

An interactive data analysis app built with **Streamlit** and **Pandas**, designed to explore and visualize insights from a diamonds dataset. This tool allows users to filter data, understand distributions, and observe relationships between carat, cut, color, and price.

## ✨ Features

- Upload and filter a diamonds dataset (`diamonds.csv`)
- Exclude invalid entries (e.g. zero dimensions)
- Normalize and remap quality labels (e.g., `Ideal → Excellent`)
- View correlation matrices and boxplots for different attributes
- Intuitive sidebar controls for interactivity
- Clean and responsive layout using Streamlit

## 🚀 Getting Started

### Prerequisites

Make sure you have **Python 3.7+** and the following packages installed:

bash
pip install streamlit pandas matplotlib seaborn

git clone https://github.com/edvinrunhellen/knowledge_control_python.git
cd knowledge_control_python

## Run streamlit app
streamlit run app.py - (inside streamlit_app)
